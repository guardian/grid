# End-to-end tests

Playwright + [`playwright-bdd`](https://vitalets.github.io/playwright-bdd/) e2e tests that
run against a full Grid stack. Scenarios live in [`features/`](features) (Gherkin) with the
step definitions in [`steps/`](steps).

## Running the tests

The Grid services run **on the host** (in the devcontainer) via `sbt <svc>/run` (Play dev
mode, live recompilation). Only the backing infrastructure (Elasticsearch, LocalStack) runs
under Testcontainers. A host Caddy process provides the `https://*.media.<domain>` browser
routing that a developer's dev-nginx provides locally.

```bash
cd e2e-tests
npm ci
npx playwright install --with-deps chromium
npm test
```

The first run is slow: Play compiles each service on its first request. Override the
readiness timeout with `GRID_STARTUP_TIMEOUT_MS` if needed. Boot logs for the services are
written to `$TMPDIR/grid-app.log`.

Requirements (provided by the devcontainer — see [`.devcontainer/devenv.yaml`](../.devcontainer/devenv.yaml)
and [`.tool-versions`](../.tool-versions)): a JDK 11, `sbt`, Node, `caddy`, Docker, and the
native image tools (GraphicsMagick, ImageMagick, `pngquant`, `exiftool`).

Useful commands:

```bash
npm run test:headed     # run with a visible browser
npm run test:report     # open the last HTML report
npm run test:ui         # open browser and test suite, run tests at your leisure
```

Traces are captured `on-first-retry` (see [`playwright.config.ts`](playwright.config.ts)),
so a failed test on CI leaves a trace you can open with `npx playwright show-trace`.

## How they work

Playwright's `globalSetup` ([`global-setup.ts`](global-setup.ts)) stands up everything the
tests need:

1. a shared Docker network;
2. **Elasticsearch** and **LocalStack** (the backing infrastructure), under
   [Testcontainers](https://testcontainers.com/);
3. the **CloudFormation core stack** (`dev/cloudformation/grid-dev-core.yml`) and seeded
   buckets, provisioned into LocalStack;
4. per-service config, generated by `dev/script/generate-config/service-config.js` and
   written to `~/.grid`, with endpoints rewritten to `localhost`;
5. all eight Grid Play services run on the host via `sbt <svc>/run`
   ([`testcontainers/app.ts`](testcontainers/app.ts));
6. a host **Caddy** reverse proxy on `:443` for the `https://*.media.<domain>` browser
   origins ([`testcontainers/proxy.ts`](testcontainers/proxy.ts)).

Elasticsearch is then seeded with image fixtures, and the resolved Kahuna base URL is
exposed to the tests. `globalTeardown` stops the host processes and containers and cleans up.
