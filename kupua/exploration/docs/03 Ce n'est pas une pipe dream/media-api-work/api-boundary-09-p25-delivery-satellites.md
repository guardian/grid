### F2. Existing Bootstrap And Host Facilities Have Concrete Limits

[KahunaConfig](../../../../../kahuna/app/lib/KahunaConfig.scala#L16), [controller serialization](../../../../../kahuna/app/controllers/KahunaController.scala#L52) and [main template](../../../../../kahuna/app/views/main.scala.html#L55) already supply aliases, organisation, image types, agency-pick inputs, AI/download flags and UI copy. They also supply media-api/auth link elements. This is rendered `_clientConfig`, not a JSON response from media-api. P24's full ConfigurationController/CropOption inspection establishes only the bare crop-variation array; the complete [route file](../../../../../media-api/conf/routes#L44) corroborates that sole configuration route. Reuse its existing configuration sources/serialization ingredients, not the crop endpoint as a general bootstrap.

The [host controller's login helper](../../../../../rest-lib/src/main/scala/com/gu/mediaservice/lib/auth/BaseControllerWithLoginRedirects.scala#L14) handles provider-selected redirects and fresh-session entry, including optional-login behavior. [Kahuna security configuration](../../../../../kahuna/app/KahunaComponents.scala#L24) explicitly builds connect/image/frame/script sources. [Services](../../../../../common-lib/src/main/scala/com/gu/mediaservice/lib/config/Services.scala#L40) derives distinct origins, overrides only a subset, and constructs CORS origins separately. [GridComponents](../../../../../rest-lib/src/main/scala/com/gu/mediaservice/lib/play/GridComponents.scala#L32) installs CORS/CSRF/security/gzip and provider-selected auth. [Authentication](../../../../../rest-lib/src/main/scala/com/gu/mediaservice/lib/auth/Authentication.scala#L47) retains principal precedence and 401/403/419 outcomes. No actual credential provider or private config was accessed.

Current D3 fetch assumes same-origin `/api`; singleton/quota/tree explicitly include credentials. Choosing direct service origins therefore requires an intentional transport/credentials and CORS/CSP/auth-return integration, not deleting the Vite prefix. The Vite origin override is development wiring, not an approved deployed policy. Public source proves facilities exist, not that a proposed Kupua origin is admitted.

Retain P23/P24's configuration distinctions: public default rights provider is runtime-configurable, not universally the vendored Guardian list; aliases include server `matchViaExistence` semantics absent from the local config interface; effective rights, fuzziness, vector/model availability and queryable identifiers require non-sensitive deployment-owner confirmation. A bootstrap must consume the selected allowed fields before registry/query construction, without claiming every server policy can or should be duplicated in the browser.

### F4. Expiry Must Be Joined To Presentation Identity

[RoundedExpiration](../../../../../common-lib/src/main/scala/com/gu/mediaservice/lib/aws/RoundedExpiration.scala#L7) requests nearest-ten-minute rounding plus twenty minutes, approximately 15-25 minutes from signing. S3 computes remaining signature duration with a one-second minimum. This is requested expiry, not a guarantee against earlier credential invalidation or a proof of byte-identical signed URLs. Configured thumbnail CDN URLs use a separate unsigned branch. No expiry field, delivery refresh scheduler or permission-refresh guarantee is provided to these consumers.

P20's source cases are confirmed against complete current detail, preview, StableImg and prefetch originals:

- The 30-entry [decoded set](../../../../src/lib/image-prefetch.ts#L80) and in-flight map are ID-keyed. Completion deletes from the **current** session by ID, so an old loader can remove a newer same-ID request's tracking. A successful thumbnail fallback can also trigger the centre's unconditional `markFullResLoaded(imageId)`. Neither establishes that the present full rendition is decoded.
- Same-ID replacement is insufficient to update [neighbour URL memos](../../../../src/components/ImageDetail.tsx#L605), zoom effects or preview's stored image/URL. Expired or renewed URLs need a delivery identity/refresh decision across all these owners, not only a changed helper.
- [Standalone detail](../../../../src/components/ImageDetail.tsx#L245) cancels obsolete callbacks but does not bind retained standalone state to the requested ID or clear A when starting absent B. A can remain the selected image after B fails. Nullable failure is not proof that B does not exist, and must never remove selection membership.
- [Detail error fallback](../../../../src/components/ImageDetail.tsx#L820) compares absolute element.src with a relative thumbnail string; repeated failure need not reach the intended terminal fallback. [Preview](../../../../src/components/FullscreenPreview.tsx#L473) has a missing-URL placeholder but no image-error handler. [StableImg](../../../../src/components/StableImg.tsx#L40) correctly resolves URLs for equality; its data-committed flag does not universally suppress later writes.
- Grid/table hide a failed image with inline display:none. Delivery-refresh acceptance must cover recovery of the reused element as well as selection of a new URL; this inspection does not claim a performed browser recovery failure.

**Smallest consequence:** make rendition identity and bounded on-demand refresh part of S6a/S10's client acceptance, including loader/session ownership and same-ID renewal. Reuse singleton GET as a possible refresh source under existing visibility policy; do not mandate per-neighbour metadata fetches, background fan-out, a new signing endpoint or universal permission revocation. Retain a usable list/return path when URL, load or decode fails. These are source-supported risks and proposed acceptance, not runtime incidence or an approved repair batch.

### F5. Singleton And Metadata Reuse Needs Result-Carried Links And Overlays

[Singleton server GET](../../../../../media-api/app/controllers/MediaApi.scala#L768) checks visibility, computes principal permissions and invokes the existing writer, including requested metadata. [GridApiDataSource](../../../../src/dal/grid-api/grid-api-adapter.ts#L47) currently returns only unwrapped ImageData through an identity function: outer links/actions are lost, nested fields are not S1-normalized, 401/419/other errors throw, and no timeout is introduced. Its [tests](../../../../src/dal/grid-api/grid-api-adapter.test.ts#L272) explicitly assert that mixed null/throw contract. The module README's active-detail/mirror-search descriptions are stale; no active singleton adapter caller was found.

[S1's D3 mapper](../../../../src/dal/grid-api-search-adapter.ts#L35) correctly normalizes valid canonical fields and returns overlays without store writes, but its wire type/loop omits outer delivery links. Assets survive the spread; optimised/download templates do not. Share this normalizer when a second real consumer is introduced, preserving the raw nested Scala response for existing clients. Do not normalize the server globally or mistake `mergeReconciledFields` for this implementation.

[Fresh search publication](../../../../src/stores/search-store.ts#L2415) replaces supplied overlays; [extension](../../../../src/stores/search-store.ts#L2573) checks cancellation before retaining tuples/upserting overlays and publishing the window. P18-P22's complete lifecycle/assertion review supplies the broader guards and absence qualifications; this packet's store ranges are only the explicit rechecks below. [useEnrichedImage](../../../../src/hooks/useEnrichedImage.ts#L26) selects by ID and memoizes image/overlay references; [deriveImage](../../../../src/lib/derive-enriched-image.ts#L93) uses overlay policy ahead of its computed baseline, not just the raw canonical policy fields. [Enrichment store](../../../../src/stores/enrichment-store.ts#L68) has no TTL and skips empty upserts.

**Consequence:** S6a returns normalized image plus relevant envelope delivery/action information and overlay, with caller-owned ID/request publication and quiet absence. S6b additionally preserves P21's whole-logical-read/selection-session guards. Do not route standalone GET through bulk or let an adapter mutate stores. Decide overlayless/same-ID/off-buffer retention deliberately under P22/P23's policy qualifications; a null optional response does not confer authorization or prove missing membership. No auth toast or changed shared D3 refusal policy is approved by the unused adapter's old comments.

### F7. Downloads And Cropper Must Remain Semantically Intact

[Kahuna downloads](../../../../../kahuna/public/js/services/image/downloads.js#L43) gates on the download link and distinguishes secure, preview, original-download and optimized-download URLs; zipped downloads fetch credentialed arraybuffers. [Kahuna usages](../../../../../kahuna/public/js/services/image/usages.js#L60) consumes nested resources/actions, not Kupua's flat model. No active Kupua download command was found in the searched source; preserving existing Grid behavior is not permission to add a new Kupua write-capable workflow.

[Original download](../../../../../media-api/app/controllers/MediaApi.scala#L441) streams S3 with content disposition and metrics; [optimized download](../../../../../media-api/app/controllers/MediaApi.scala#L494) freshly signs source/PNG and redirects through imgops; crop download is separate. When enabled, these GET paths call usage recording on behalf of the principal. [postToUsages](../../../../../media-api/app/controllers/MediaApi.scala#L521) has an explicit InDesign exemption and fire-and-forget status handling. [Usage receiver](../../../../../usage/app/controllers/UsageApi.scala#L241) validates and emits a download usage group. A raw secure asset is therefore **not equivalent** to download, nor is a read-only HTTP verb proof of no side effect. Do not use download routes for preview/prefetch or call them as review probes. The handler checks visibility; the writer's optional download-link gating is a distinct contract, not proof that the handler enforces all UI download restrictions.

[Cropper](../../../../../cropper/app/controllers/CropperController.scala#L189) forwards principal auth, requests `include=fileMetadata` and parses [SourceImage](../../../../../common-lib/src/main/scala/com/gu/mediaservice/model/SourceImage.scala#L10). It then needs valid, oriented/raw dimensions, secure source, MIME and colour metadata. [Crops.makeExport](../../../../../cropper/app/lib/Crops.scala#L109) consumes those fields to fetch/transform; [CropsTest](../../../../../cropper/test/lib/CropsTest.scala#L12) asserts type/alpha decisions and names, not a new API integration. Keep full GET, expanded metadata, nested shape and shared links unchanged. No crop mutation, image generation or upload was executed.

### F8. Complete Journey Account And Verification Limits

The joined delivery journey is: route entry/resident or standalone identity -> selected DAL request -> canonical normalization plus overlay/delivery data -> existing guarded publication -> grid/table/detail metadata and URL selection -> centre/side/prefetch/zoom load/decode -> existing traversal/history/return. P18-P21 own the completed ordered-data/geometry/selection traces; P25 completes the delivery/bootstrap/service joins above, not a second interaction engine. Failure/expiry must remain separate from data membership and positional tuples. Ordinary live drift, one semantic sort, useful limits and approximate deep landing/histograms remain accepted.

**Assertions read, not run:** Argo helpers preserve false/link-only shapes and identity normalization; singleton tests assert proxy URL, signal forwarding and mixed failure outcomes; prefetch tests mock URLs/Image and cover cadence/radius/visible-request protection; collection tests cover subtree arithmetic, Node tests optional parent data; quota tests cover basic failure absence; RoundedExpiration tests rounding/minimum horizon; ContentDisposition tests filenames; ImageResponse tests aliases/newlines/deletability; MediaApiTest tests the download-recording exemption; CropsTest covers type/alpha/names. [ImageOperationsTest](../../../../../common-lib/src/test/scala/com/gu/mediaservice/lib/imaging/ImageOperationsTest.scala#L15) is disabled and explicitly lacks crop conversion tests. These inspected assertions do not establish signed-rendition renewal, browser pixels, deployed auth/CORS, or full transform parity. No project-wide absence-of-tests claim follows.

Reuse [P20 F5](api-boundary-09-p20-detail-traversal.md#L66): actual resident P14 forward/backward and P15 fullscreen identity/decode evidence exists; JB5 measures exit settlement after keys, not the whole traversal. Keep its original-source/canonical references, revisions, cache/topology/source-identity limits and D3 investigation interpretation. This packet did not newly read canonical histories or rerun them. No new campaign is requested; a future chosen topology's genuinely unanswered media/load question is separate from re-proving the working core.
